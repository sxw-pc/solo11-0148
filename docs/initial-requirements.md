# 初始需求：河段水质预警采证台

使用者为流域监测站、实验室和取水口值守员。四类输入可以迟到或相互冲突；系统必须保存原始来源并对后续结论作可审计重算。

1. 测站资格账以**采样时刻**核校准有效期及设备归属。调站后原站证书不自动继承，同号同版异系数证书进入争议。
2. 样本保管账按瓶号、封签、交出与接收人及时间核连续链。重复传输不增加独立样本数；异内容同瓶号进入争议。方法过期或检出限不足的低值不能撤回警示。
3. 河段事件账按有向河边和传播时差纳入证据，至少两份独立高值才确认警示。有效迟到复测替代被复测样本，追加事件版本，不覆盖旧警示证据。
4. 公众通告账需要覆盖当前受影响的每个取水口，逐个跟踪送达。事件降级时对旧版原收件人打开撤回义务，全部回执齐全才结案。

每个入口可独立输出自己的状态。跨系统引用需保留版本，导入与决定在 SQLite 事务内提交；中断和重复输入不得形成重复事件、送达或撤回。报告列原始哈希、当前决定、历史版本与未完成义务。所有样例是虚构文件，工程离线运行。
